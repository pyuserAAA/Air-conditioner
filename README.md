# 瑞丰空调维修有限公司 - 官方网站

大型空调维修专业服务企业官网，面向工厂、商场、酒店、医院、写字楼、数据中心等企业客户。

## 技术栈

- 纯 HTML/CSS/JS 单页面网站
- 响应式设计，适配移动端/平板/桌面
- 深蓝商务专业风格
- 无依赖、零构建、开箱即用

## 功能模块

- 🏠 **首页** - 企业形象展示、核心数据
- 🔧 **业务范围** - 6大服务项目展示
- 📊 **成功案例** - 6个行业合作案例
- 🏢 **关于我们** - 公司介绍、核心优势
- 📞 **联系我们** - 联系信息 + 在线报修表单

## 使用方式

直接用浏览器打开 `index.html` 即可查看网站。
